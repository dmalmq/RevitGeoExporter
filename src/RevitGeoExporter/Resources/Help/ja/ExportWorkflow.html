Export Dialog

エクスポートの流れ

新しいエクスポート画面では、標準的な操作を先に見せ、技術的な設定は展開式にまとめています。初めてのユーザーでも、通常のエクスポートなら迷わず進める構成です。

Export to Include in export Coordinate system Advanced options

Export to

  • 出力フォルダーは必須項目です。ダイアログ上部で早い段階に確認できます。
  • Browse... を使って保存先を変更できます。
  • 出力形式を選択します。GeoPackage（すべてのレイヤーを 1 ファイルにまとめる）か、Shapefile（レイヤーごとに .shp セットを作成する）から選べます。
  • ビュー、フィーチャータイプ、出力先がそろうまで Export は有効になりません。

Include in export

  • Units、Details、Openings、Levels、Fixtures を選択します。
  • Fixtures は、Accepted Openings に登録されたファミリ名（例: 自動改札機）から IMDF の fixture フィーチャーを書き出します。詳しくは 設定とプロファイル を参照してください。
  • 画面上のラベルは分かりやすい表現ですが、出力には unit、opening、fixture など既定のレイヤー名が使われます。
  • 少なくとも 1 つのビューと 1 つのフィーチャータイプを選ぶと、Preview を開けます。

Coordinate system

  • 状態カードに、現在の共有座標と解決された EPSG が要約表示されます。
  • 共有座標ではなく変換出力が必要な場合だけ、Change coordinate settings を開いて CRS や EPSG を変更します。
  • CRS プリセットのドロップダウンから、よく使う投影座標系を選べます。日本の平面直角座標系など地域別のプリセットがグループ化されており、選択すると EPSG 欄も自動で更新されます。
  • より詳細なモデル座標の情報が必要なときは、View technical details を展開します。

Advanced options

Advanced options は初期状態で折りたたまれており、主な作業を邪魔しません。次のような場合に展開してください。

  • Unit source は Units を有効にしたときだけ表示され、Rooms を選んだ場合のみ部屋カテゴリパラメータが表示されます。
  • Simplify stair units と Simplify escalator units は、階段・エスカレーターのジオメトリを整理した平面形状にまとめます。Revit の生ジオメトリで出力が乱れる場合に有効です。
  • Linked models — 有効にすると、読み込み済みの Revit リンクのうちどれをエクスポート対象に含めるかをチェックリストで選択できます。座標モードは各リンクにも適用されます。
  • Incremental mode は既定ですべての選択ビューを書き出します。「changed only」に切り替えると、前回から内容が変わっていないビューをスキップします。
  • Packaging mode は、出力ファイルのまとめ方を制御します（ビューごと / 建物ごと / レベルごと）。
  • プロファイル — 独立した 3 種類のプロファイルがあります。エクスポートプロファイル（ダイアログの状態）、スキーマプロファイル（出力フィールドの定義）、検証ポリシープロファイル（どの検証で止めるか / 警告にとどめるか）。それぞれにセレクターと Manage… ボタンがあります。詳しくは 設定とプロファイル を参照してください。
  • Diagnostics、GIS package、package legend、QGIS artifacts の各トグルで、エクスポートに同梱する追加ファイルを制御します。Open output folder と Launch QGIS はエクスポート後のショートカット動作です。
  • Edit category mappings でプロジェクト側の上書きエディター（床タイプ、部屋カテゴリ、ファミリカテゴリ）を開きます。

3D セクション ボックス エクスポート（試験的）

選択した各プランビューに対して、エクスポーターが一時的な 3D ビューを作成し、レベル付近をセクション ボックスで切り出すモードです。階段・エスカレーター・シャフトの切り抜きが通常の平面抽出ではうまくいかないプロジェクト向けの代替経路です。

  • Use 3D section box per floor (experimental) でモードを有効化します。
  • Top (m) はレベル床面の上方向へ切り出す距離です（既定値 1.2 m）。
  • Bottom (m) はレベル床面より下方向のオフセットです（既定値 0.0 m）。
  • Keep temp 3D views for inspection (debug) を有効にすると、エクスポート後も一時 3D ビューがモデルに残り、何が取得されたかを直接確認できます。通常運用ではオフのままにしてください。

フッターのアクション

  • Preview で現在の選択内容のプレビュー画面を開きます。
  • Batch… は、ダイアログを開き直さずに複数のビュー セットを連続してエクスポートできます。
  • Export で検証、ファイル書き出し、結果サマリーが行われます。

書き出し前の確認

フッターには現在の選択内容が要約表示され、実際の書き出し前には検証が実行されます。

  • ジオメトリや警告、カテゴリ割り当てを確認したい場合は プレビューと割り当て を開きます。
  • どのような項目がエクスポートを止めるかは 検証と診断 を参照してください。
