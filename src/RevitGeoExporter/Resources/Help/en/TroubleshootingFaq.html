Troubleshooting / FAQ

Use this page when export behavior is technically correct but still unexpected for the current project or receiving workflow.

Why is something missing in QGIS?

Start with Preview and Assignments and the validation dialog. Missing vertical units, unsnapped openings, unsupported families, and filtered-out layers usually appear there before export completes.

Why did a floor export as unspecified?

The floor type name did not resolve to a known category. Use preview assignments or the project mappings area in Settings and Profiles to add an exporter-side override.

Where are settings stored?

Global defaults and project mappings are stored in the RevitGeoExporter application data area. The settings hub can import, export, and reset each scope independently.

Can the add-in modify the Revit model?

No. Preview assignments, mappings, diagnostics, and help content are exporter-side only. They do not rename Revit elements or write category decisions back into the model. The exception is temporary 3D views created when 3D section box export is active — these are removed at the end of the export unless the debug toggle is enabled.

Stairs or escalators are missing in a plan view

Stairs and escalators are clipped to shaft openings and the view's cut plane. If they don't appear, try the Simplify stair units / Simplify escalator units toggles in Advanced options, and if the result is still off, enable 3D section box export for that view.

When should I enable 3D section box export?

Try it when standard plan extraction loses vertical circulation, shaft-clipped geometry, or pieces that overlap multiple floors. The exporter builds a temporary 3D view per plan view and slices geometry with a section box around the level. Use Keep temp 3D views for inspection (debug) to leave the temporary views in the model and confirm what was captured.

Still blocked?

  • Review Validation and Diagnostics for issues that can stop the export.
  • Review Export Workflow to confirm the selected layers, folder, and coordinate mode.
